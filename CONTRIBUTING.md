# Contributing

Keep experimental results tied to raw evidence and session metadata. Label new implementations and generated configurations clearly. Do not replace the original source files; add corrected versions with a changelog and provenance.

For code changes, run the offline unit tests. ROS-facing changes additionally require a recorded Jazzy integration check; changes to vehicle command handling require SITL validation and an explicit frame/timeout review.

Do not put credentials or private telemetry into issues. Report bugs with package versions, node/topic output, minimal steps and relevant logs. Licensing and contributor roles remain subject to confirmation by the project team.
